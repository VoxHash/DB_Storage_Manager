## Supporting the project

DB Storage Manager's core and built-in plugins are free. Optional premium plugins are priced to stay affordable worldwide (from US$1.99/month per plugin, US$24 one-time, see [ROADMAP.md](ROADMAP.md)) and include updates while your subscription is active, or for the current major version with a one-time licence. If a price is out of reach, write to contact@voxhash.dev for a discount. You can also donate without buying anything: https://github.com/sponsors/VoxHash

For licence problems (key not accepted, wrong product, lost key) include the plugin id and the masked key shown in the Plugins tab, never the full key.

## Before Reporting

1. Check existing issues
2. Review [docs/troubleshooting.md](docs/troubleshooting.md) and [docs/faq.md](docs/faq.md)
3. Confirm Python 3.10–3.12 and a single project `.venv` install (`pip show db-storage-manager` should point only at this repo; avoid duplicate user/system copies)
4. Include OS, Python version, install command output, and reproduction steps
